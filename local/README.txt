牛马 nmer — 用户私有目录（勿提交 Git）

本目录存放含 API Key、个人偏好与 OpenClaw 本地状态，每台机器独立。

常见文件：
  CursorShortcut.ini      主程序热键与偏好
  PromptTemplates.ini     提示词模板
  user_studio.json        智能定制（LLM API、路径、ttyd）
  user_studio.backup.json 智能定制自动备份
  niuma_chat_llm.json      Niuma Chat LLM 密钥同步
  openclaw-state/         OpenClaw CLI 工作区状态（勿手动删除非需重置）

模板与内置 catalog 仍在 config/（如 user_studio.defaults.json）。
