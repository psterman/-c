# 牛马（nmer）软件介绍

## 1. 软件定位
牛马（nmer）是一款面向 Windows 的桌面效率增强工具，基于 AutoHotkey 主控，围绕 `CapsLock` 作为统一唤起键，将代码处理、全局搜索、剪贴板管理、截图流程、提示词管理、语音输入和悬浮 UI 入口整合为一套“低打断、高响应”的工作流系统。

## 2. 核心功能

### 2.1 CapsLock 快捷工作流中枢
- 以 `CapsLock` 长按/组合键作为统一交互入口。
- 支持解释、重构、优化、分割、批量处理等高频动作。
- 支持动态快捷键映射与用户自定义按键方案。

### 2.2 智能剪贴板与历史管理
- 连续复制收集（多段文本聚合）。
- 合并粘贴与一键回填。
- 剪贴板历史面板（含检索、分类、删除、清空）。
- 基于 SQLite/FTS 的历史数据存储与检索能力。

### 2.3 SearchCenter 全局搜索中心
- 统一搜索入口，支持多分类检索与结果列表交互。
- 可结合 Everything 与本地搜索能力进行快速文件定位。
- 支持键盘导航、区域焦点切换、批量搜索触发。

### 2.4 截图与编辑工作流
- 区域截图、截图工具栏、截图编辑面板协同。
- 支持截图后处理、复制、保存等操作。
- 提供截图插件化接口与工作流状态同步。

### 2.5 Prompt 与 AI 操作增强
- PromptQuickPad 快速采集与管理。
- 支持提示词模板（分类、系列、默认模板映射）。
- 可将选中文本快速注入预设提示词流程，提升 AI 协作效率。

### 2.6 语音与终端扩展能力
- 语音输入/语音搜索模块化接入。
- 集成 ttyd 终端桥接能力，可用于 CLI 协作场景。

### 2.7 悬浮交互层
- 悬浮工具栏、悬浮球、拖拽洞（Hole Overlay）等入口形态。
- 支持不同激活模式切换，适配多屏与桌面常驻场景。

## 3. UI 设计与交互结构

### 3.1 UI 组成
项目采用“主控脚本 + 多 WebView 面板”的组合式 UI：
- 快捷操作面板
- SearchCenter 搜索中心
- 剪贴板管理面板
- 设置面板（Settings）
- 截图工具栏/编辑器
- 悬浮工具栏与悬浮球
- PromptQuickPad

### 3.2 交互特征
- 键盘优先：大量操作可无鼠标完成。
- 低打断：通过悬浮层和轻量弹出面板减少上下文切换。
- 场景联动：搜索、复制、截图、提示词、终端之间可形成串联工作流。

### 3.3 可配置性
- 快捷键可重映射。
- 面板位置与多屏显示可配置。
- Prompt、分类、模板、显示模式可个性化调整。

## 4. 技术架构

### 4.1 总体架构
- **控制层**：AutoHotkey v2 主脚本（热键、窗口管理、流程编排）。
- **界面层**：WebView2 承载 HTML/CSS/JS 面板。
- **能力层**：模块化 `modules/*.ahk`（搜索、截图、剪贴板、语音、悬浮层等）。
- **数据层**：SQLite（剪贴板历史等持久化数据）。
- **搜索引擎层**：Go `searchcore` + Everything/rg 等本地检索能力。

### 4.2 关键技术栈
- AutoHotkey v2
- WebView2（含本地资源映射与消息桥）
- SQLite / FTS
- Go（SearchCenterCore、全文检索相关组件）
- Everything SDK（Windows 文件检索）
- GDI+/WinClip/OCR 等本地能力库

### 4.3 模块化组织方式
- `modules/`：业务功能模块
- `assets/`：前端静态资源与图标
- `searchcore/`：Go 搜索内核
- `Data/`：本地持久化数据
- `config/`：用户配置与映射
- `tools/`：诊断与桥接工具

## 5. 典型应用场景

### 5.1 开发者高频编码场景
- 选中代码后快速触发解释/重构/优化。
- 搜索中心统一检索代码片段、文件与命令入口。

### 5.2 资料收集与内容整理
- 连续复制多段信息并自动聚合。
- 使用剪贴板历史追溯、复用、清理知识素材。

### 5.3 文档与截图协同
- 快速截图并直接进入编辑与分发流程。
- 将截图和文本内容组合后输入到 AI 或文档系统。

### 5.4 多工具并行工作台
- 借助悬浮工具栏/悬浮球实现常驻入口。
- 通过可配置热键把常用动作压缩到单次击键。

## 6. 产品价值总结
牛马（nmer）的核心价值是把分散在编辑器、系统搜索、剪贴板、截图和 AI 交互之间的步骤，收敛为一套统一、可配置、低延迟的键盘驱动工作流。它适合高频处理文本与代码、需要快速上下文切换的开发与知识工作场景。
