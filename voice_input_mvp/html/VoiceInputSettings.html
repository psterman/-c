    设计原则

    页面只负责录制触发源，不把用户按钮偷偷改成固定键。执行器内部再把这个触发源映射到语音输入动作。

    兼容说明

    像 Y6 这种同一个物理键混出 `Volume_Down / Volume_Up` 的设备，会被归并成一个“同源分组”，触发时只进一套状态机。

    触发源录制

    录制用户真正按下的单键或单按钮。页面采集原始事件，后端决定是否归并成同源分组。

    语音状态机

    触发源只负责“谁来触发”，真正执行的是语音输入状态机。

    第一次单击voice_start / 发送右 Alt
    取消窗口内再次单击voice_cancel / 发送 Esc
    第二次有效触发后等待延迟并执行 voice_send
    第三次开始回到单击循环
